# Blackridge media assets

These are AI-generated portfolio-demo media for the fictional Blackridge Build Co. brand.

The homepage intentionally uses SVG wrapper files that embed optimized WebP image data. This keeps the media self-contained and avoids binary clipping/corruption when assets are written through the connected GitHub workflow.

## Homepage slot mapping

- `blackridge-ridge-house-hero.svg` — Ridge House hero: contemporary stone, glass, and dark-metal mountain residence overlooking alpine water.
- `blackridge-ridge-house-winter.svg` — Ridge House project card: the same architectural language in a winter setting, supporting “Stone, glass, and winter light.”
- `blackridge-pine-hollow-twilight.svg` — Pine Hollow project card: low-profile, restrained luxury among mature pines at twilight.
- `blackridge-ridge-house-interior.svg` — Ridge House interior: warm stone, light oak, and panoramic glazing.
- `blackridge-mill-creek-addition.svg` — Mill Creek Addition: historic stone fabric joined to a contemporary dark-metal/glass addition.

Each image was reviewed against the homepage caption and section context. No slot requires replacement at this stage.
